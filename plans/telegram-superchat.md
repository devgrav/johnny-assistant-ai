## Цель (на этот этап)

Суперчат в Telegram: одна супергруппа-форум с двумя топиками («Johnny» и «Финконсультант»),
в каждом — свой бот. Andrey в одном чате, оба агента отвечают в своём топике, не перебивая.
Финконсультант пока **ограниченный** — простой агент только чтобы протестить механику
суперчата. Полную настройку (Snowball, профиль, read-only и т.д.) не делаем.

## Решение по формату

Вариант **А** (выбран Andrey 2026-10-08): одна супергруппа-форум, топики Johnny /
Финконсультант, у консультанта свой бот.

## Что уже готово

- `assistants/PLAN.md` — сводка решений по финконсультанту (отдельный агент, read-only,
  облако; приватность не критична).
- `financial-agent/skills/financial-critic/SKILL.md` — 5 шагов проверки рекомендаций.
- Архитектура модель-агностична: MCP и скиллы не зависят от модели.
- Сейчас в системе только `johnny-assistant` + один Telegram-аккаунт `default`.

## Что нужно (блокеры)

1. **Tailscale Serve** — чтобы Andrey мог ввести токен нового бота через Control UI
   (см. план `plans/tailscale-secure-input.md`). Это зависимость №1.
2. **Новый бот** для финконсультанта: @BotFather → `/newbot` → токен присылает через
   защищённый ввод (Control UI), не в открытый чат.
3. Создать супергруппу-форум в Telegram, включить топики, добавить обоих ботов.

## Шаги (после Tailscale)

1. Andrey создаёт бота в @BotFather, токен вводит через Control UI (маскированное поле).
2. Завести агента `financial-agent` с дешёвыми дефолтами: flash heartbeat,
   `thinkingDefault=low`, ограниченный профиль (тестовый).
3. Привязать второго бота как отдельный Telegram-аккаунт (не `default`).
4. Настроить routing/bindings: оба бота в одной супергруппе-форуме, каждый отвечает
   в своём топике.
5. Проверить механику: сообщение в топике «Johnny» → отвечаю я; в топике
   «Финконсультант» → отвечает консультант; перебиваний нет.

## Отложено (вернуться отдельно)

- Полная настройка финконсультанта: Snowball-ключ, профиль/read-only, критик-скилл в проде.
- Хранение секретов через панель управления — целиком завязано на Tailscale Serve (см. выше).
