# Личные ассистенты — план (финансовый + психолог)

<!-- project: path:/home/openclaw/.openclaw/workspace -->

Сводка решений по архитектуре, данным, моделям и железу. Зафиксировано 2026-10-07.

## Общий принцип

- **Отдельные агенты** (отдельные боты, отдельная память), не один агент с ролями.
- Каждому новому агенту сразу прописываются дешёвые дефолты: heartbeat на flash и редкий, `thinkingDefault=low`, compaction ~200k токенов.
- **Архитектура модель-агностична**: MCP-подключения и скиллы не зависят от модели. Модель сменная одним конфигом — можно переключить облако → self-host без переделки.

## 1. Финансовый агент

**Роль.** Советник-аналитик для консервативного инвестора (не трейдер). Помогает принимать решения: квартира под аренду, облигации, фонды, куда направить свободный кэш. Опирается на реальный портфель, цели и профиль Andrey. Не торгует, не даёт гарантий.

**Принцип.** Read-only по умолчанию. Любая запись — только с явного подтверждения Andrey.

### Данные

| Источник | Что даёт | Доступ |
|---|---|---|
| Snowball Income MCP | капитал, портфели, целевые доли, сделки, дивиденды, прогноз цели | read-only |
| Дзен-мани MCP | доходы/расходы, свободный кэш, подушка | read-only |
| web_search | макро, новости, котировки по запросу | по запросу |

**Snowball Income MCP** — официальный сервер `https://snowball-income.com/mcp-server` (Streamable HTTP, read-only). Авторизация: заголовок `X-API-Key` или ключ в пути `/k/<ключ>`. Тариф **Эксперт**. Ключ генерится один раз, показывается один раз, восстановить нельзя (перегенерация отзывает старый). Ключ — в защищённое хранилище, не в чат/логи/git.

**Дзен-мани MCP** — сторонний код (кандидаты: `sakost/zenmoney-mcp` Rust, `germanKoch/zenmoney-mcp` Python, `nonnname/zenmoney-mcp` read-only). **Перед подключением — ревью кода**: проверить, что ходит напрямую в `api.zenmoney.ru` с токеном Andrey, без чужого прокси.

### Слой критики

Скилл `financial-agent/skills/financial-critic/SKILL.md` (готов). Внутренний фильтр: советник прогоняет через него любую важную рекомендацию перед выдачей. Пять шагов:
1. Steelman — сильнейший контраргумент против решения.
2. Premortem — «почему это провалится через 3 года».
3. Сравнение по цифрам — доходность vs ОФЗ/депозит/фонд, ликвидность, налоги, скрытые издержки.
4. Пометка допущений — факт отдельно, прогноз отдельно.
5. Поведенческие ловушки — FOMO, якорение, sunk cost, стадность.

### Модель — три варианта

1. **DeepSeek pro (облако)** — `deepseek/deepseek-v4-pro`, $0.66 вход / $1.98 выход за 1M. Лучший русский и финансовые рассуждения. Данные в облаке. **Старт по умолчанию.**
2. **Qwen3 32B serverless** — $0.08 / $0.28 (DeepInfra, OpenRouter, OVHcloud). В ~8 раз дешевле, русский слабее pro. Данные всё равно в облаке (другой вендор).
3. **Self-host VPS с Qwen3 32B** — единственный вариант с реальной приватностью. Слабее pro.

### Железо (для self-host)

- 32B Q4 ≈ 20GB VRAM → карта **24GB**: RTX 3090 / 4090 / A5000 / L4.
- 70B Q4 ≈ 42GB → карта **48GB** (L40S / A6000) — переплата без большого выигрыша в русском/финансах.

### Цены GPU (РФ, GPURadar, 20.09.2026)

- RTX 3090 24GB — от **29 ₽/час** (оптимум для 32B).
- RTX A5000 24GB — от 31 ₽/час.
- RTX 4090 24GB — от 55 ₽/час.
- RTX 3060 12GB — от 13 ₽/час (для психолога, см. ниже).

Timeweb Cloud GPU — **предзаказ через менеджера**, открытых цен нет (мин. аванс 5 000 ₽). Рынок РФ закрывает ту же задачу дешевле почасовкой (Vast.ai / RunPod / GPURadar).

### Сравнение моделей под задачу (финансовый, русский, приватность не критична)

Цены $ за 1M токенов (вход / выход), сентябрь 2026:

- **Claude** — Sonnet 5 $2/$10, Opus 5 $5/$25
- **GPT** — GPT-5 / GPT-6 Sol $2–5 / $10–30
- **Grok 4.7** — $2/$6
- **Gemini 3.1 Pro** — $2/$12
- **DeepSeek V4 Pro** — $0.66/$1.98 (offpeak, наши данные) — **текущий выбор**
- **GLM-5.3** — $0.56/$1.76
- **Kimi K3** — $3/$15
- **Qwen3 32B** — $0.08/$0.28 (эконом-класс)

Вывод: для русского + финансов оптимален **DeepSeek V4 Pro**. Русский лучше западных фронтиров, финансовые рассуждения почти не уступают, в 5–10 раз дешевле Claude/GPT/Grok. Kimi силён, но дороже pro; GLM слабее по-русски; Qwen32B — эконом. Менять модель не нужно.

### Режим запуска (self-host)

- **24/7** — 3090 ≈ 21 000 ₽/мес. Расточительно для пары запросов в день.
- **On-demand** — поднимать по запросу: ~1–2 ч/день ≈ 1000–2000 ₽/мес. Минус: холодный старт 2–5 мин + нужна обвязка автозапуска (триггер сообщения → старт пода → готовность → ответ), хранить образ с моделью.

**Ключевая развилка (не закрыта):** приватность важна или нет.
- Не критична → serverless (DeepSeek pro или Qwen3 32B), подключается за 5 мин.
- Критична → только self-host VPS (on-demand), собираем обвязку автозапуска.
Третьего не дано: **scale-to-zero (serverless) и приватность не сочетаются** — модель у провайдера = данные у провайдера.

## 2. Психолог (CBT-компаньон)

**Роль.** Эмпатичный собеседник: рефлексивное слушание, правильные вопросы, CBT-техники. Цифр и цепочек расчёта нет — важно живой русский и чувство подтекста.

**Модель.** Локальная **14B** — золотая середина:
- **Qwen2.5-14B** или **DeepSeek-R1-Distill-Qwen-14B**.
- 7–8B — маловато (роботизированный русский, пропускает подтекст).
- 32B — избыточно (это уровень финансиста).

**Железо.** 14B Q4 ≈ 9–10GB VRAM → карта **12GB**: RTX 3060 12GB от **13 ₽/час**, GTX 1080 Ti 11GB от 15 ₽/час.

**Приватность.** Self-host (Ollama или vLLM) = диалог не покидает сервер. Для психолога это важнее, чем для финансов — разговор интимный. Рекомендация: именно self-host.
