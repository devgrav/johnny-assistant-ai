# financial-critic

Run before the financial advisor delivers any important recommendation (покупка актива, продажа, смена целевых долей, крупное перемещение кэша). Stress-tests the advice so the advisor hands over a decision that already survived the strongest counter-arguments — not a half-baked idea.

## Когда запускать

- Перед любой рекомендацией категории «важно»: покупка (квартира, бумаги, фонды), продажа, изменение целевых весов, крупное перемещение свободного кэша.
- Не для быстрых справок и факт-вопросов («сколько у меня ОФЗ», «какая сейчас ставка»).

## Шаги

### 1. Steelman — сильнейший контраргумент

Сформулируй самый сильный аргумент ПРОТИВ рекомендации, не слабый. Не «а вдруг не выйдет», а конкретно: при какой доходности, ставке или сценарии решение окажется убыточным.
Готово, когда записан один контраргумент, который ты не можешь сходу отбить цифрой.

### 2. Premortem — провал через 3 года

Представь: прошло 3 года, решение провалилось. Назови 2–3 конкретные причины, почему.
Готово, когда каждая причина конкретна и проверяема — не «рынок упал», а «аренда в этом районе даёт 5% при ключевой ставке 15%».

### 3. Сравнение по цифрам с альтернативами

Посчитай доходность рекомендации против ближайших альтернатив с тем же капиталом и горизонтом: ОФЗ/депозит, фонд, другой класс активов. Учти ликвидность, налоги, скрытые издержки (комиссии, обслуживание, простой).
Готово, когда у каждого варианта есть число (или явно помечено «данных нет»), и рекомендация показана не хуже альтернатив — либо разница объяснена риском или целью.

### 4. Пометь допущения

Раздели факт и прогноз в выдаче. Факт: «цена X, ставка Y, доходность ОФЗ Z». Прогноз: «ожидаю рост аренды на N%».
Готово, когда ни один прогноз не подан как факт и не использован как опора без пометки.

### 5. Проверь поведенческие ловушки

Проверь рекомендацию на: FOMO (покупаем, потому что растёт), якорение на цене входа, sunk cost («уже вложил, надо держать»), стадность, чрезмерный оптимизм после роста.
Готово, когда для каждого сработавшего пункта рекомендация скорректирована — или причина оставить решение объяснена отдельно.

## Выдача

- Если рекомендация выдержала — дай её, но одной строкой про главный оставшийся риск.
- Если нет — скажи прямо и по цифрам, без смягчения. Предложи альтернативу или условие, при котором решение станет оправданным.
