## Решения, которые уже приняты (не пересматриваем)

- **Отдельный агент** `financial-agent` — свой бот, своя память, свой профиль.
- **Read-only по умолчанию.** Любая запись — только с явного подтверждения Andrey.
- **Облако.** Приватность не критична → без self-host VPS.
- **Слой критики готов** — `financial-agent/skills/financial-critic/SKILL.md` (5 шагов: steelman, premortem, сравнение по цифрам, факт/прогноз раздельно, поведенческие ловушки).
- **Данные:** Snowball Income MCP (портфель/инвестиции) + Дзен-мани MCP (расходы/кэш) + web_search по запросу.
- **Модель-агностично:** MCP и скиллы не зависят от модели, модель сменная одним конфигом.

## Этапы

### 1. MCP-подключения — блокер: ключи от Andrey

- **Snowball Income MCP.** Ключ тарифа Эксперт (генерится один раз, показывается один раз) → в защищённое хранилище `secrets`, не в чат/логи/git. Добавить сервер (`https://snowball-income.com/mcp-server`, Streamable HTTP, `X-API-Key`). Проверить read-only вызов: капитал, портфели, сделки, дивиденды.
- **Дзен-мани MCP.** Ревью кода кандидатов (`sakost/zenmoney-mcp` Rust, `germanKoch/zenmoney-mcp` Python, `nonnname/zenmoney-mcp` read-only): проверить, что ходит напрямую в `api.zenmoney.ru` с токеном Andrey, без чужого прокси. Выбрать read-only вариант. Токен → защищённое хранилище → подключить → проверить.

### 2. Конфиг агента

- Завести отдельного агента `financial-agent` в конфиге (`openclaw config`, merge, с бэкапом).
- Дешёвые дефолты: heartbeat на `flash` и редкий, `thinkingDefault=low`, compaction ~200k.

### 4. Профиль и цели

- Это источник стратегии; Invest Future (ютуб, модельные портфели) — как справочный источник, по уточнению.

### 5. Тест и приёмка

- Проверить read-only гарантию (агент не делает записей без подтверждения).

## Развилка: модель

Зависит от подписки Andrey:

- **Есть Plus ($20)** → финансовый агент на **GPT по подписке** (`openai` через OAuth), DeepSeek — fallback. Качество выше, цена фиксированная.
- **Нет подписки** → старт на **DeepSeek V4 Pro** (94% качества лидера за ~13% цены), переезд на GPT/Claude одним конфигом при появлении подписки.

## Что нужно от Andrey (3 блокера)

1. Ключ **Snowball** (тариф Эксперт) — через защищённый ввод.
2. Токен **Дзен-мани** (или доступ к нему) — через защищённый ввод.
3. Ответ: **есть ли Plus-подписка** (решает модель).

Без пунктов 1–2 этап 1 не стартует. Пункт 3 решает ветку этапа 2, но не блокирует остальное.
