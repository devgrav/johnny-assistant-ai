## Решения, которые уже приняты (не пересматриваем)

- **Отдельный агент** `financial-agent` — свой бот, своя память, свой профиль.
- **Read-only по умолчанию.** Любая запись — только с явного подтверждения Andrey.
- **Облако.** Приватность не критична → без self-host VPS.
- **Слой критики готов** — `financial-agent/skills/financial-critic/SKILL.md` (5 шагов: steelman, premortem, сравнение по цифрам, факт/прогноз раздельно, поведенческие ловушки).
- **Модель-агностично:** MCP и скиллы не зависят от модели, модель сменная одним конфигом.

## Данные

- **Snowball Income MCP** — капитал, портфели, целевые доли, сделки, дивиденды, прогноз цели (read-only).
- **web_search** — макро, новости, котировки по запросу.
- **Дзен-мани MCP** — отложено (подключим позже, отдельным этапом после Snowball).

## Этапы

### 1. Snowball MCP — блокер: ключ от Andrey

Ключ тарифа Эксперт (генерится один раз, показывается один раз) → в защищённое хранилище `secrets`, не в чат/логи/git. Добавить сервер (`https://snowball-income.com/mcp-server`, Streamable HTTP, `X-API-Key`). Проверить read-only вызов: капитал, портфели, сделки, дивиденды.

### 2. Telegram: новый бот + супергруппа-форум — блокер: token бота от Andrey

Целевая структура (со слов Andrey):

- **Новый бот** для финконсультанта (создаёт Andrey через @BotFather) → отдельный Telegram-аккаунт в конфиге OpenClaw (у Johnny сейчас аккаунт `default`, у фин-агента будет свой).
- **Супергруппа-форум** с двумя топиками (общего пока нет):
  - топик **Johnny** — я;
  - топик **Финконсультант** — фин-агент.

Точную схему routing по топикам (кто в каком топике читает/отвечает, как не дать ботам перебивать друг друга в общем) проверю по докам OpenClaw на этапе выполнения — здесь фиксирую целевую картинку.

### 3. Конфиг агента

- Завести отдельного агента `financial-agent` в конфиге (`openclaw config`, merge, с бэкапом).
- Дешёвые дефолты: heartbeat на `flash` и редкий, `thinkingDefault=low`, compaction ~200k.
- Привязать к новому Telegram-аккаунту (бот из этапа 2).
- Модель — **GPT по подписке** (решено, DeepSeek fallback).

### 4. Скиллы и промпт

- Подключить скилл `financial-critic`.
- Системный промпт советника: роль (советник-аналитик консервативного инвестора, не трейдер), read-only правило, обязательный прогон любой важной рекомендации через слой критики.

### 5. Профиль и цели

- Завести `USER.md` агента с профилем Andrey: цели, горизонт, риск-профиль, свободный кэш, подушка.
- Invest Future (ютуб, модельные портфели) — как справочный источник, по уточнению.

### 6. Тест и приёмка

- Прогнать сценарии: обзор портфеля; «куда деть свободный кэш»; рекомендация по облигациям/фондам — каждый через слой критики.
- Проверить read-only гарантию.
- Проверить, что в супергруппе каждый бот отвечает в своём топике, а в общем — оба корректно.
